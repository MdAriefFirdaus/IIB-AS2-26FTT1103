The project is to establish connection between the local computer of the user with an ssh server and to create a
script file named sysinfo. This script when executed will provide info on the system of the server which will
include the hostname, the OS/kernel, memory usage, disk usage, CPU load, uptime and create a report which will
be saved in a directory. In order to run the script, the command ~/ds1202-project/scripts/sysinfo.sh will
be needed to be entered inside of the terminal. The git workflow used was by initialising a git directory which
includes a main branch called main and a feature branch called feature-Logging,CpuLoad,ReportWrite. The contents of
the feature branch has been merged with the main branch. Two commits have been created so far since the
initialisation of this git repository. The screenshots of the evidence PDF folder will include a screenshot of
the ssh-keygen output, a screenshot of passwordless ssh login to the server, ls -la showing the ~/ds1202-project
structure and its permissions, A screenshot of an output running sysinfo.sh and a screenshot of git log --graph
--oneline --all showing the commit history and branches
